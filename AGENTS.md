# AGENTS.md — read-me-first for coding agents

1. Read **`AGENT_CONTEXT.md`** top-to-bottom — it is the always-current
   quick-reload file (environment, live behavior, architecture map,
   conventions, deferred work).
2. Then read the NEWEST snapshot in **`AGENT_CHECKPOINT.md`** (session
   history). Note: the older archive is not strictly date-sorted — scan the
   `## Snapshot` headings.
3. Update `AGENT_CONTEXT.md` when its facts go stale; append a new
   `AGENT_CHECKPOINT.md` snapshot before risky steps and after milestones.
